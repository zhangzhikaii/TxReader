收入为正、支出为负。各币种是原币的合计（不涉及汇率），最右一列按本月汇率折算。汇差盈亏 = 上月底存量 ×（本月汇率 − 上月汇率），和结余页同一个算法；人民币合计 = 折算 + 汇差，应等于结余页的月度差额

结余 = 期初余额 + 起始月之后的交易。汇差盈亏 = 上月底存量 ×（本月汇率 − 上月汇率）。「—」表示这个账户没有这个币种。隐藏的账户也算在合计里

每周填一次。证券的金额 = 数量 × 现价；成本价是每单位的平均成本（可不填），持仓盈亏 = 金额 − 数量 × 成本价，「原币」是证券自己的币种，「折算」按账户的币种；现金可以是任何币种。有行情代码的证券从 Yahoo Finance 取价格（只把代码发出去）：这周内是最新价，可以点「更新价格」；这周结束后换成这周最后一个交易日的收盘价，以后不再改；自己改过的价格（手填）不会被覆盖。新的一周会沿用上一周的持仓，只换价格，买卖了再进去改数量。折算用这周周日所在月份的月汇率，占比 = 这一行折算后的金额 ÷ 账户市值（含现金）。成本 = 结余页这个账户在这周周日的余额（期初余额 + 之后的交易），较结余盈亏 = 市值 − 成本，它包括现金、已经卖掉的盈亏和汇差，持仓盈亏只算现在拿着、填了成本价的证券。只是看看，不会记成交易
