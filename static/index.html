连接 Outlook

在 Azure 门户的「应用注册」里建一个应用：平台选「Web」，加一个重定向 URI；API 权限加上 Microsoft Graph 的 Mail.Read 和 offline_access（委托）；再新建一个客户端密码。把「应用程序（客户端）ID」、密码的「值」和重定向 URI 填在这里，保存后点「连接 Outlook」登录邮箱，或者在下面直接填 refresh token

回调地址空着就用 。Azure 里 http 只允许 localhost；已经注册过 http://localhost:8000 的话直接填它也行（首页会把授权码转过来）

不在网页里登录，直接填 refresh token

用别的方式拿到的 refresh token（同一个 Client ID 的）贴在这里，保存时会马上试着刷新一次，确认能用。access token 只有 1 小时有效，填它没用

邮件规则

一种通知邮件一条规则：发件人一致（写成 @域名 表示这个域名下的所有地址）、标题包含关键词（空着表示不限）的邮件才会读。三个正则各有一对括号，括号里的部分就是取出来的值；金额一律记为支出。改完离开输入框就会保存
